PINAR TOKUR PORTFOLIO — GITHUB PAGES KURULUMU

1. ZIP dosyasını aç.
2. İçindeki TÜM dosya ve klasörleri GitHub'daki pinartokur.github.io reposunun ana dizinine yükle.
3. Mevcut index.html dosyasının üzerine yaz.
4. "assets" klasörünün adını ve yerini değiştirme.
5. Değişiklikleri kaydet/commit et. GitHub Pages birkaç dakika içinde güncellenir.

Pakette bulunanlar:
- index.html: Portfolio sitesi
- assets/: Tasarım ve font dosyaları
- pinar-profile.png: Profil fotoğrafı
- Pinar_Tokur_CV.pdf: İndirilebilir CV
- favicon.svg: Tarayıcı ikonu

İletişim bilgileri veya metinlerde değişiklik yapmak istersen index.html dosyasını düzenleyebilirsin.
